RAVELPHONE HDD - prototipo PWA

1) Su Windows, per provarla subito:
   - installa Python se non presente
   - apri Prompt dei comandi dentro questa cartella
   - esegui: python -m http.server 8080
   - apri http://localhost:8080 nel browser

2) Per usarla su iPhone come app, pubblica questa cartella su un hosting HTTPS (es. GitHub Pages, Netlify, Cloudflare Pages o un tuo server).
   Poi apri l'indirizzo in Safari > Condividi > Aggiungi alla schermata Home.

3) PDF:
   Da Anteprima premi “Crea / salva PDF”. Si apre la stampa del browser; su iPhone la schermata di stampa permette di condividere/salvare il documento come PDF.

Nota: i rapportini dello Storico sono salvati localmente nel browser del dispositivo. In una versione successiva si può aggiungere database/cloud, login, invio email e backup.
